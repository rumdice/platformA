  2. 플레이어 게임 진입 시퀀스

  sequenceDiagram
      participant C as 클라이언트
      participant AUTH as Auth.API
      participant TICK as Ticketing.API
      participant MATCH as Matching.API
      participant REDIS as Redis Cluster
      participant GAME as Game.Server
      participant DB as MySQL

      Note over C,DB: ① 인증
      C->>AUTH: POST /api/Auth/login {username, password}
      AUTH->>DB: SELECT player WHERE username=?
      AUTH->>REDIS: SET refresh:{userId} (TTL 7일)
      AUTH-->>C: JWT AccessToken + RefreshToken

      Note over C,REDIS: ② 대기열 (선택적)
      C->>TICK: POST /api/Ticket/register (Bearer JWT)
      TICK->>REDIS: ZADD ticket:{event} score=timestamp userId
      TICK-->>C: 현재 순위

      Note over C,GAME: ③ 매칭 요청
      C->>MATCH: WebSocket 연결 /hubs/matching
      C->>MATCH: POST /api/GameMatch/RequestMatch
      MATCH->>REDIS: RPUSH queue:gamematch:1v1 userId

      Note over MATCH,GAME: ④ 백그라운드 매칭 (1초 폴링)
      REDIS-->>MATCH: LLEN >= 2 감지
      MATCH->>REDIS: LPOP × 2 (player1, player2)
      MATCH->>REDIS: INCR global:room_id → roomId
      MATCH->>REDIS: PUBLISH channel:match_success {roomId, [p1,p2]}
      MATCH->>C: SignalR "MatchFound" {roomId, serverAddr}

      Note over GAME,REDIS: Game.Server 방 생성
      REDIS-->>GAME: 구독 수신 channel:match_success
      GAME->>GAME: GameRoomManager.CreateRoom(roomId)

      Note over C,GAME: ⑤ 게임 접속
      C->>GAME: TCP Connect :7777
      GAME->>GAME: GameSession 생성
      C->>GAME: C_LoginPacket (JWT 토큰)
      GAME->>GAME: JWT 검증 → 방 입장 (미완성)
      loop 게임 진행
          C->>GAME: C_MovePacket (바이너리)
          GAME->>GAME: JobQueue → GameRoom 처리
          GAME->>C: S_MovePacket broadcast
      end
