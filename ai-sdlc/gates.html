    AI_SDLC Gate 판정

    SDLC 게이트는 /done과 /pr 실행 시 PostgreSQL DB에서 조회하는 플래그다. 모든 게이트가 충족되어야 PR이 생성된다.

    게이트 목록

    게이트 DB 컬럼 설정 스킬 설명
    requirement_done ai_jobs.requirement_done /requirement 요구사항 명세 파일 생성 완료
    impact_done ai_jobs.impact_done /impact 영향 범위 분석 완료
    test_generated ai_jobs.test_generated /test-gen 테스트 케이스 생성 완료
    review_completed ai_jobs.review_completed /review 코드 리뷰 완료
    adr_required ai_jobs.adr_required /requirement DESIGN_REVIEW true이면 ADR 생성 필요 (PR 차단)

    게이트 조회 쿼리

    SELECT requirement_done, impact_done, test_generated, review_completed, adr_required
FROM sdlc.ai_jobs
WHERE branch = 'my-branch';

    스킬에서 사용법

    python .github/scripts/db_write.py \
  --action get-gates \
  --branch "$(git branch --show-current)"
# 출력: requirement_done=true impact_done=true test_generated=true review_completed=false adr_required=false

    수동 gate 설정

    스킬 실행 없이 게이트를 수동으로 통과시켜야 할 때:

    # test_generated — 테스트가 이미 충분한 경우
python .github/scripts/db_write.py \
  --action upsert-job --branch my-branch --test-generated

# impact_done — 문서 전용 변경으로 impact 불필요 시
python .github/scripts/db_write.py \
  --action upsert-job --branch my-branch --impact-done

    주의: 게이트를 수동으로 통과시키는 것은 해당 단계가 실제로 불필요하다고 판단할 때만 사용하라.

    GitHub Actions gate-check

    sdlc-gate-check.yml이 PR 생성 시 동일한 게이트를 검사한다. 로컬 /done → push → GitHub Actions gate-check 순서로 이중 검증된다.
