# 현재 스프린트 및 백로그 상태 조회

`AI/SPRINT.md`와 `AI/BACKLOG.md`를 읽어 현재 상태를 분석하고 보고한다.

`$ARGUMENTS`가 있으면 해당 키워드(예: `BACK-005`, `Auth`, `Migration`)와 관련된 항목을 필터링한다.

---

## 수행 순서

### 1단계: 파일 읽기

`AI/SPRINT.md`와 `AI/BACKLOG.md` 파일을 읽는다.

### 2단계: 현재 스프린트 분석

가장 최근(번호가 가장 큰) 스프린트를 찾아 아래 항목을 출력한다:

```
## 스프린트 #N — <목표>

### 진행 중
- [ ] <항목>   ← 미완료 항목 전체

### 완료
- [x] <항목>   ← 완료 항목 전체 (5개 이하일 경우 전체, 초과 시 최근 3개만)

### 대기
- [ ] <항목>   ← 대기 항목 (있을 경우)
```

`$ARGUMENTS`가 있으면 키워드와 관련 없는 항목은 제외한다.

### 3단계: 백로그 요약

`AI/BACKLOG.md`에서 미완료 항목을 우선순위별로 요약한다:

```
## 백로그 (미완료)

### 긴급
- #BACK-XXX: <제목> (<예상 크기>)

### 높음
- #BACK-XXX: <제목> (<예상 크기>)

### 보통
- #BACK-XXX: <제목> (<예상 크기>)

### 낮음
- #BACK-XXX: <제목> (<예상 크기>)
```

`$ARGUMENTS`가 있으면 관련 항목만 필터링한다.

### 4단계: 권고사항

현재 스프린트의 "진행 중" 항목이 **비어 있으면**:
> "현재 진행 중인 태스크가 없습니다. `/plan <작업 설명>`으로 새 태스크를 시작하세요."
> 백로그 최우선 항목 1~2개를 다음 작업 후보로 제안한다.

진행 중 항목이 있으면:
> 현재 작업 상태를 한 줄로 요약하고, 다음으로 해야 할 구체적인 액션을 안내한다.
