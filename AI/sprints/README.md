# AI_SDLC Sprints

이 디렉터리는 AI_SDLC 스프린트별 상세 작업 파일을 보관한다.

## 구조

- `AI/sprints/sprint-NNN.md` — 개별 스프린트 상세 (단일 진실 공급원)

`AI/SPRINT.md`와 `AI/cost-log.md`는 삭제됨 — DB(`sdlc.ai_jobs`)와 이 디렉터리가 단일 진실 공급원.

## 명명 규칙

```
sprint-NNN.md    NNN = 3자리 zero-padded 스프린트 번호
```

## 새 스프린트 작성 방법

`/plan` 스킬이 `AI/sprints/sprint-NNN.md`를 자동 생성한다. 수동 작성 불필요.
