### 1. 빌드 false negative 수정

**증상**: 세션 시작 시 `dotnet build PlatformA.sln` 이 "실패"로 표시되지만 실제 컴파일은 성공.  
**원인**: `-q` (quiet) 플래그가 .NET 10 SDK의 병렬 빌드에서 "stale target 재빌드" 알림을 `MSBUILD : error` 레벨로 출력하여 exit code 1 반환.  
**해결**: `session-start.sh` 및 `done/SKILL.md`에서 `-q` → `--verbosity minimal` 변경.

### 2. python3 Windows Store 스텁 오류 수정

**증상**: `/plan` 스킬 호출 즉시 실패 (exit code 49).  
**원인**: Windows PATH에서 `C:\Users\...\WindowsApps\python3.exe` (Microsoft Store 스텁)가 실제 Python 3.9보다 우선 순위가 높아 Store 앱 설치 창을 열려다 실패.  
**해결**: 6개 스킬 파일(`plan`, `requirement`, `impact`, `start`, `pr`, `workreport`)의 `python3 -c "..."` 명령을 bash 동등 명령으로 전면 교체.
