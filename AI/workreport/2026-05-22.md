- `.github/workflows/pr-merge-sync.yml` — `pull_request closed + merged` 이벤트 감지
- `.github/scripts/sync_merged_pr.py` — 브랜치명으로 task JSON 탐색, 3개 파일 자동 갱신
  - task JSON: `status → "done"`, `completed_at`, `pr_url`
  - SPRINT.md: `- [ ] → - [x]`
  - cost-log.md: `/pr` 스킬 미실행 경로에서만 행 추가
- Idempotent 설계: 이미 `status: "done"`이면 중복 갱신 없음
- **트러블슈팅**: 첫 실행 시 `main` 브랜치 보호(required status check)에 막혀 push 실패 → `BOT_PUSH_TOKEN` (Fine-grained PAT) 시크릿 적용으로 해결
