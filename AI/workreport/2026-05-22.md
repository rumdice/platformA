## 주요 작업 내용

### 1. SDLC 파이프라인 Gate 강화 (PR #50, 스프린트 #25, 규모: M)

PR 생성 단계(`/pr`)에서 후속 단계 실행 여부를 검사하지 않아 누락 가능성이 있던 문제를 해결.

- `/pr` 스킬에 3단계 게이트 검사 추가:
  - `test_generated` — 코드 변경이 있으면 `/test-gen` 실행 여부 필수 검사 (미실행 시 PR 차단)
  - `review_completed` — 고위험 변경(핵심 라이브러리·DB·인증·Redis) 또는 10파일 초과 시 `/review` 필수
  - `impact` — 미실행 시 경고 출력 후 계속 진행
- `/done` 스킬에 `/test-gen` 미실행 경고 추가 (중단 없이 경고만)
- task JSON 스키마에 `impact`·`steps` 필드 추가, `/plan` 템플릿 반영
- `AI/AI_SDLC(pipeline).txt` 단계 번호 및 게이트 정책 갱신

### 4. PR 머지 자동 동기화 워크플로우 구축 (PR #53·#54, 스프린트 #26, 규모: M)

PR 머지 후 task JSON·SPRINT.md·cost-log 갱신을 수동으로 알려야 했던 문제 자동화.

- `.github/workflows/pr-merge-sync.yml`: `pull_request closed + merged` 이벤트에 반응
- `.github/scripts/sync_merged_pr.py`: 브랜치명으로 task JSON 탐색 후 3개 파일 자동 갱신
  - task JSON: `status → "done"`, `completed_at`, `pr_url` 설정
  - SPRINT.md: `- [ ] → - [x]` 교체 (idempotent)
  - cost-log: `/pr` 스킬 미실행 경로에서만 행 추가
- **트러블슈팅**: 첫 실행에서 `main` 브랜치 보호(required status check)에 막혀 push 실패
  - 원인: `github-actions[bot]`은 브랜치 보호를 우회할 수 없음
  - 해결: Fine-grained PAT(`BOT_PUSH_TOKEN` 시크릿) 적용 → `enforce_admins: false` 조건으로 우회
