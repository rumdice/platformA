    Matching API

    1v1 게임 매칭 대기열 및 주식 주문 처리를 담당하는 서비스입니다. SignalR Hub(/hubs/matching)를 통해 매칭 결과(MatchFound / MatchTimeout)를 Push합니다.

    항목 값
    개발 환경 기본 URL https://localhost:7002
    런타임 .NET 10.0
    인증 방식 Bearer Token (JWT) — Authorization 헤더 필요

    공통 오류 응답 형식

    { "message": "설명 메시지" }

    엔드포인트

    POST /api/gamematch/request

    Lobby 서버 전용: 매칭 요청 및 즉시 게임 서버 접속 정보 반환. JWT 인증 없이 Lobby 서버 내부에서 호출됩니다.

    요청 Body

    필드 타입 필수 제약 조건
    userId int ✓ 범위 1, int.MaxValue, ErrorMessage = "UserId는 1 이상이어야 합니다."
    gameType string ✓ 최대 50자 
    {
  "userId": 0,
  "gameType": "<gameType>"
}

    응답 202

    응답 JSON 형식은 구현 코드 또는 Swagger(/swagger)를 참조하세요.
