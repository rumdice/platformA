## 수정 내역 (이번 실행 전 적용)

### ServiceManager.cs — Game.Gomoku TcpPort 추가

**문제**: `ServiceSpec`의 `HealthUrl`이 `http://localhost:7779/healthz`로 설정되어 있었음.  
Windows에서 `HttpListener`는 비관리자 권한으로 해당 주소 바인딩에 조용히 실패하므로, 헬스체크 HTTP 서버가 실제로 기동되지 않음.  
`KillByPort`도 7779 포트를 기준으로 종료를 시도해 실제 프로세스(7778 TCP)가 남아 재시작 시 충돌.

**수정**: `TcpPort: 7778` 추가 → `PingAsync`가 TCP 연결 체크로 전환, `KillByPort`도 7778 포트로 올바르게 종료.

```csharp
// Before
new("Game.Gomoku", "PlatformA/PlatformA.Game.Gomoku", "http://localhost:7779/healthz"),
// After
new("Game.Gomoku", "PlatformA/PlatformA.Game.Gomoku", "http://localhost:7779/healthz", TcpPort: 7778),
```
