# Utils API

IP 조회, URL 단축, 클릭 통계 등 유틸리티 기능을 제공합니다.

| 항목 | 값 |
|------|-----|
| 개발 환경 기본 URL | `https://localhost:7004` |
| 런타임 | .NET 10.0 |
| 인증 방식 | 없음 (공개 API) |

---

## 공통 오류 응답 형식

```json
{ "message": "설명 메시지" }
```
