    RefreshTokenService

    Redis 기반 Refresh Token 관리 서비스.

    [키 구조] refresh:{playerId} → refreshToken 문자열

    • 유저 1명당 Redis 키가 정확히 1개이므로, 재로그인 시 SET 덮어쓰기만으로 기존 토큰이 자동 폐기됩니다 (단일 세션 정책, 중복 로그인 불허).
    • Refresh Token 포맷: "{playerId}:{random}" — playerId를 파싱하여 역방향 인덱스 없이 Redis 키를 직접 계산합니다.

    RedisManager.ExecuteAsync를 통해 Polly 회로차단기 + 재시도가 적용됩니다.
